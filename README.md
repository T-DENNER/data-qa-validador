# Data QA Validador

Validador de dados desenvolvido em Python para garantir a qualidade e integridade de bases de dados.

## Sobre o projeto
Este projeto foi criado para automatizar a verificação de dados, identificando inconsistências, valores nulos, duplicidades e erros de formatação antes que eles impactem análises e relatórios.

## Funcionalidades
- Validação de campos obrigatórios
- Detecção de valores nulos e duplicados
- Verificação de tipos de dados
- Relatório de erros encontrados

## Tecnologias utilizadas
- Python
- Pandas

## Como executar
1. Clone o repositório: `git clone https://github.com/T-DENNER/data-qa-validador.git`
2. Instale as dependências: `pip install -r requirements.txt`
3. Execute o validador: `python main.py`
